# Rud Android Edge Detection Viewer

This project is implemented by **Rudraksh Agnihotri** as part of the *Android + OpenCV-C++ + OpenGL + Web (R&D Intern)* assessment.

## Features

- Android app that captures camera frames
- Native C++ (OpenCV) edge detection via JNI
- OpenGL ES 2.0 renderer to display processed frames
- `/web` TypeScript viewer that shows a sample processed frame with basic stats

## Tech Stack

- Android SDK (Kotlin)
- NDK + JNI (C++)
- OpenCV (C++)
- OpenGL ES 2.0
- TypeScript + HTML (web viewer)
